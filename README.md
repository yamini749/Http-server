# Http-server

A simple, zero‑configuration command‑line HTTP(S) static file server built with Node.js.

## 🚀 Features

- Serve static files from a directory
- Supports HTTP and optionally HTTPS (TLS)
- Auto directory listings
- CORS, caching control, custom headers, gzip/brotli compression
- Easy proxy fallback for SPA or API
- Configurable via CLI args or programmatically

## 🧰 Prerequisites

- [Node.js](https://nodejs.org/) (v12+ recommended)
- npm (bundled with Node.js)

## 📦 Installation

Globally using npm:
```bash
npm install -g http-server
